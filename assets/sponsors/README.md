# Sponsor logos

Central home for sponsor logos that have no stable public URL of their own.
Every gofiber README links them from here, so renaming or moving a file breaks
all of them at once.

Reference as:

```text
https://raw.githubusercontent.com/gofiber/.github/main/assets/sponsors/<file>
```

Prefer a sponsor's own CDN URL when they host one. SVG over PNG.
