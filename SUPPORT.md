# Support

Thank you for using Fiber. This page explains where to get help for any
repository of the [gofiber](https://github.com/gofiber) organization.

## Read the documentation

- [docs.gofiber.io](https://docs.gofiber.io/): API reference and guides, plus
  the documentation of the contrib middleware, storage drivers and template
  engines
- [FAQ](https://docs.gofiber.io/extra/faq/): answers to common questions
- [Recipes](https://github.com/gofiber/recipes): runnable examples, also
  published at [docs.gofiber.io/recipes](https://docs.gofiber.io/recipes/)
- [Awesome Fiber](https://github.com/gofiber/awesome-fiber): middleware,
  boilerplates, articles and tools from the community

## Ask a question

Usage questions are answered fastest on our
[Discord server](https://gofiber.io/discord).

You can also open an issue with the **Question** template in the repository
your question is about. Please search the existing issues first, and do not
post the same question in several places.

## Report a bug or request a feature

Open an issue in the repository where the code lives and use its bug report or
feature request template:

- Framework core and built-in middleware:
  [gofiber/fiber](https://github.com/gofiber/fiber/issues/new/choose)
- Contrib middleware:
  [gofiber/contrib](https://github.com/gofiber/contrib/issues/new/choose)
- Storage drivers:
  [gofiber/storage](https://github.com/gofiber/storage/issues/new/choose)
- Template engines:
  [gofiber/template](https://github.com/gofiber/template/issues/new/choose)
- Recipes:
  [gofiber/recipes](https://github.com/gofiber/recipes/issues/new/choose)

Documentation problems belong in the repository the page is written in, see
the [contributing guidelines][contributing]. Problems with the website itself
belong in [gofiber/docs](https://github.com/gofiber/docs).

## Report a security vulnerability

Do not open a public issue for a security problem. Report it privately with
**Report a vulnerability** in the **Security** tab of the affected repository.
The [security policy][security] lists the other ways to reach the maintainers.

## Code of Conduct

Everyone taking part in the Fiber community is expected to follow our
[Code of Conduct][coc].
